# Changelog

## 0.2.0

- Added Minecraft `26.1.1` support for Wolkensprung.
- Added per-course reward rules with item tiers, command tiers, fallback rewards, daily limits, new-best-only payouts, and once-per-tier rewards.
- Added a personal case beam so active runners can spot their spawned case from a distance.
- Updated the Wolkensprung NPC with a custom in-game skin.
- Improved quest text and expanded localized English and German runtime messages.
