# Wolkensprung for Minecraft 26.3

Version folder for the `26.3` release line.

- Minecraft: `26.3`
- Java: `25`
- Mod version: `0.2.3`

See the root [README](../README.md) and [wiki](../docs/wiki/getting-started.md) for setup and command documentation.

## Build

From this folder, with Java 25 configured:

```powershell
.\gradlew.bat build
```
