# Localization And Content

## Languages

Wolkensprung supports German and English through the normal Minecraft language setting.

- `de_de`
- `en_us`

Switching the client language changes NPC dialog, runtime quest messages, and admin feedback automatically.

## NPCs

The dedicated Wolkensprung NPC entity uses the custom mod skin shipped with the mod.

Legacy named Armor Stands are still recognized as quest givers for compatibility, but new setups should use the dedicated NPC entity.

## Quest cases

Each active runner gets their own spawned finish case.

- The case is tied to the active run.
- The highlight beam is only visible to the player on that run.
- The case disappears when the run is completed.
